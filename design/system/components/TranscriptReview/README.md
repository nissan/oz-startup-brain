Shown after the founder has explicitly stopped recording and before anything is sent. The transcript is editable; ambiguous place names, numbers and acronyms are flagged beneath it. Only the corrected text is submitted and the recording is not retained. "Discard transcript" abandons it; there is no auto-send.

Consumer provides: `transcript`, `flagged` (`[{word, reason}]`), `onSend(text)`, `onDiscard`.
