The one button family. Use `primary` for the single most useful action in a view (it carries the sage fill), `secondary` for everything else, and `quiet` for in-line actions that read as links. Never put two primary buttons in one card, and never more than one in one view: a component that is repeated in a view (the next-step card) takes its emphasis from the parent. A *selected* state (a pressed starter task, a chosen option) is not an action and is never sage; it uses `ironbark-tint` with an `ironbark` border. Disabled buttons keep their label and explain why in nearby text; they never hide.

Consumer provides: `children` (the label, sentence case, verb first), `variant`, `onClick`, optional `disabled`. Minimum target 44px tall on phones.
