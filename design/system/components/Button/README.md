The one button family. Use `primary` for the single most useful action in a view (it carries the sage fill), `secondary` for everything else, and `quiet` for in-line actions that read as links. Never put two primary buttons in one card. Disabled buttons keep their label and explain why in nearby text; they never hide.

Consumer provides: `children` (the label, sentence case, verb first), `variant`, `onClick`, optional `disabled`. Minimum target 44px tall on phones.
