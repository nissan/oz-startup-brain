One next action with its reason, what to check, its evidence state and the next human or source door. The planner returns at most three of these per request. The evidence row is mandatory; if the state is `outside` or `needs-check`, the card may still show the action but the consumer must also show the matching `LimitPanel`.

The inspect action ("Show supporting passage") is secondary by default because the card repeats: the parent view chooses at most one card to carry `emphasis="primary"`, so that a view with three cards still has one sage action.

Consumer provides: `title`, `why`, `check` (strings), `evidence` (`{state, date, publisher}`), `door`, `onInspect`, optional `onAsk`, optional `emphasis` (`primary` | `secondary`, default `secondary`).
