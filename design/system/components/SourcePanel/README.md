The evidence beside a claim: publisher, source-version date, verification date (shown as "unknown" when null), effective date if the claim is future-effective, the canonical link, and an excerpt only when the source is rights-cleared. For a non-cleared source the panel says so and links out instead; it never shows snapshot paths.

Consumer provides: `title`, `publisher`, `url`, `sourceVersionDate`, `verifiedAt` (nullable), `state`, optional `effectiveFrom`, optional `excerpt` with `excerptMark` for the supporting span.
