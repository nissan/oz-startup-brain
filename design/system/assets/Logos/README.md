Logo files. The mark is a single ironbark tile (`ironbark`) carrying a paper-coloured route: a start node, one bend, and a destination node filled `sage`. It is drawn from the system's own tokens and radii (tile corner = `radius-lg` at 64px), not from any existing brand.

- `mark.svg` — light-theme mark (ironbark tile, paper route, sage destination). Use on `paper` and `paper-raised`.
- `mark-dark.svg` — dark-theme mark (the dark `ironbark` tint as tile, dark paper route, dark sage destination). Use on dark `paper`.
- `wordmark-horizontal.svg` / `-dark.svg` — mark + "Oz Startup Brain" in Fraunces 600, text outlined to paths so no font is needed; ink colour `ink` / dark `ink`.
- `wordmark-stacked.svg` / `-dark.svg` — mark above a two-line wordmark, for square or narrow placements.
- `wordmark-tagline.svg` / `-dark.svg` — horizontal lockup with the tagline in Atkinson Hyperlegible 400, `ink-muted` / dark `ink-muted`.

Permitted grounds: every lockup has a light file and a dark file. Light files (dark lettering) go only on `paper` or `paper-raised`; dark files (light lettering) go only on dark `paper` or dark `paper-raised`. Pick the file for the ground, never the theme of the surrounding page: a dark panel inside a light page takes the dark file. No lockup goes on a mid-tone, a photograph, or an `ochre`, `plum` or `sage` fill.

Rules: clear space around any lockup is the height of the mark's route stroke times four (at 64px, 22px). Minimum size: mark 16px (favicon), horizontal lockup 160px wide. Do not recolour the mark outside its two themes, place it on `ochre`, `plum` or `sage` fills, rotate it, add a shadow, or set the name in another face. The wordmark is always "Oz Startup Brain" in that case; never "OSB" in running copy.
