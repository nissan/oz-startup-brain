# Delivery home

Start with the [current iteration, issue #23](https://github.com/nissan/oz-startup-brain/issues/23), then read the selected issue and its latest comments/linked PR before claiming work. This is the shared entry point for Claude, Codex and future agents. The fixture implementation and consolidation evidence are delivered; a proposed assignment does not launch a session.

- [Current consolidation assessment and start prompts](consolidation-20261108.md): completed work, remaining gates, exact provider/file boundaries and retrospective.
- [Session handover](../../HANDOVER.md): read first in any new agent session; current state, working commands, GitHub access from agent sessions, environment limits and fresh-session prompts.
- [Foundation retrospective](retrospectives/foundation-pr32-pr33.md): verified outcomes, review lessons and proposed independent next lanes.
- [Ordered product backlog](backlog.md): outcomes, dependencies and later roadmap gates.
- [Iteration 01](iterations/iteration-01.md): first bounded delivery goal and dispatch prompt.
- [Agent workflow](agent-workflow.md): assignment, handoffs, reviews, verification and completion.
- [Optional Attio-inspired pilot](attio-pilot/README.md): scoped lessons, local context/handoff tools and session prompts for a measured trial; existing workflow and live assignments remain authoritative.
- [Product roadmap](../06-delivery.md): architecture stages and release gates.
- [Visual quality](../ux/visual-quality.md): mandatory polish and review for each frontend increment.

The **issue's Delivery block is the current status/owner/iteration authority**; comments are its append-only handoff history, and PRs hold implementation and review evidence. The iteration hub lists membership and order. Repository documents explain policy, not duplicate live status. The coordinator reconciles these records at each handoff. Chat alone is not a durable decision record.

The usable board today is the linked issue index. [Native Project setup #30](https://github.com/nissan/oz-startup-brain/issues/30) is blocked on authenticated Projects write access; no native Project or automatic agent dispatch is claimed. Once configured, Project fields mirror these issues until tested synchronization is introduced.
