## Roles

- **Builds:** Codex. A Claude session does not build here.
- **Reviews:** Claude, review only, when dispatched on the pull request; the builder also reviews its own work. Tell Codex on hub issue 23 when something merges.
- **Merges:** Only when the owner says so in the conversation.

## The check command

```sh
rm -rf node_modules */*/dist && npm ci && npm run typecheck && npm test
```

Hosted CI: Yes: GitHub Actions (six jobs in checks.yml, plus source-retrieval.yml).

## What each check needs

"Cloud session" means a cloud agent session with no machine linked to it. A check that
cannot run there is a stop for that session, not a pass: say so in the pull request and
name the machine that has to run it.

| Check | Command | Needs | Runs in a cloud session |
|---|---|---|---|
| Python validators and their tests | see .github/workflows/checks.yml | Python 3 | not tried |
| Contracts, generated client, typecheck, unit tests | `npm ci && npm run check:generated && npm run check:compat && npm run typecheck && npm test` | Node 22.12 to 22.x, npm 10.9 | not tried |
| Founder journey browser tests | `npm run build && npm test -w @ozsb/web && npm run e2e -w @ozsb/web` | Playwright with Chromium | not tried |
| Raster images are Git LFS pointers | `python scripts/check-lfs-images.py` | Python 3 | not tried |
| Mac app runs and evidence archival | by hand | the Mac verifier with authenticated Git LFS | no |
